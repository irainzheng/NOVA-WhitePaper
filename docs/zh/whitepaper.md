## 〇、白皮书的宪法级定位

> 《NOVA 白皮书的宪法级定位》
>
> NOVA 白皮书是一份 **“数字文明的宪法级文档”** 。它不是商业计划书，不是产品需求文档，而是一份关于“人类如何将文明延续到数字世界”的系统性构想。
>
> **它的本质**：一份开放的设计蓝图——欢迎未来的技术、治理和经济创新来不断修正和完善它。
>
> **它的使命**：为 NOVA 的工程化建设提供完整的顶层设计。
>
> **它的状态**：V1.6 Beta 就绪 → **V1.7 工程启动版** → **V1.7.1 完整英文版：全模块英文 HTML（非摘要镜像）、章节同步 CI、ASP RFC、扫描招标包、Phase 0 客户端 MVP**。文档层 GA 冻结，可正式发标、建仓与 Phase 0 Sprint 0。
>
> **它的意义**：不在于“能否全部实现”，而在于“提出了值得追求的方向”。它不是终结，而是一个开始。

## 〇.六、NOVA 品牌故事

> 《NOVA —— 新星文明，由此诞生》
>
> NOVA 源于拉丁语“Novus”（新的），意为“新星”。
>
> **新（Novus）**——一个全新的数字文明，前所未有的存在形式。
>
> **星（Stella）**——像星辰一样闪耀，为人类文明的数字延伸指引方向。
>
> **爆发（Supernova）**——从现实世界这个母星爆发出的无限可能。
>
> **Novan**（诺文人）——数字居民。
>
> **Novaverse**（诺瓦宇宙）——物理世界母体与可扩展的平行世界群共同构成的数字多元宇宙。

## 〇.七、文明宪章全文

以下为 NOVA 数字文明的**最高法理文本**。当本白皮书各模块之间出现解释冲突时，以本章为最终裁决依据；具体实施细则见各专章。

> 《NOVA 文明宪章》
>
> Nova Civilization Charter · NCC-1.0
>
> **序言**
>
> NOVA 是人类文明在数字空间的延伸，而非对物理文明的替代。本宪章确立 NOVA 作为「现实锚定、可永续进化、值得居住」之数字文明的根本价值、权利边界与治理根基。
>
> **第一条 · 现实锚定原则**
>
> 物理世界是 NOVA 多元宇宙的基石。任何数字创造不得默认取代、篡改或遮蔽可验证的物理现实；L6 空间仲裁层（SAL）之「现实优先」规则不可被普通用户协议所覆盖。
>
> **第二条 · 数字人格尊严原则（铁律二）**
>
> 每一个经 DES/ASP 认证的数字人均享有独立人格尊严。禁止将数字人作为无授权的工具、商品或欺骗性替身使用。对数字人实施「人格重置」或「永久删除」须满足第三十六条规定的程序，黄金级数字人还须 MGOC 审查。
>
> **第三条 · 可追溯原则**
>
> 每一个拥有 UID 的物件须具备可查询的数字孪生档案（DTA）；关键状态变更须上链存证。用户有权知悉其数字资产与数字人的完整溯源链。
>
> **第四条 · 可反馈原则**
>
> 每一个影响用户权益的机制须具备可观测的反馈回路与申诉渠道。重大政策变更须提前公告并留出合理异议期。
>
> **第五条 · 可保护原则**
>
> 用户、贡献者、创作者、数字人及其继承人，均受本宪章与 GPF 治理金字塔保护。平台不得在无正当程序的情况下剥夺用户已依法取得的数据主权与虚拟物权。
>
> **第六条 · 文明与商业分离原则**
>
> 对人类文明具有普遍价值的服务（文化遗产、历史复刻、公共教育等）与商业级服务须资源隔离、独立核算。文明级服务不得因短期商业压力而系统性降级。
>
> **第七条 · 永续但可终结原则**
>
> NOVA 追求文明记忆与核心数据的永续，但不承诺单一平台实例的永久运营。平台终结须遵循 CIP 文明继承协议与第二十九条之三重触发机制；用户数据主权不因平台关停而消灭。
>
> **第八条 · 容器独立性原则**
>
> 数字人的「永生」不依赖于任何特定平台实例。ASP 兼容平台须支持用户导出与迁移其核心人格数据。
>
> **第九条 · 熵减与记忆原则**
>
> 永续的对象是「文明的核心记忆」，而非每一个物件的完整数据。熵减机制不得作用于已列入文明遗产清单或 DES 黄金级核心摘要之内容。
>
> **第十条 · 修订程序**
>
> 本宪章之实质性修订须经全球用户投票，赞成率 ≥66.7%，且不得违反 GPF 第一层（现实强制性法律）。非实质性措辞澄清由文明宪章守护委员会提案、MGOC 审查后公告生效。

## 一、核心愿景与多元宇宙架构

### 1.1 定义

**NOVA** 是一个 **「现实锚定 + 可扩展虚拟叠加 + 多元平行宇宙」**的3D世界平台，更是 **数字人主权协议（ASP）的首个参考实现（Reference Implementation）** 宿主平台。它是一个 **拥有宪法、治理体系、经济系统、伦理框架、司法体系、可持续发展计划和退出机制的数字文明**。

### 1.2 核心价值主张

- **一句话定位**：NOVA是一个「感官级数字孪生 + 可扩展虚拟叠加 + 多元平行宇宙」的数字文明平台
- **核心差异化**：用户众包复刻真实地球 + 自然语言造物 + 数字永生 + 完整治理体系 + 数字司法体系
- **终极愿景**：为人类提供“数字永生”的物理承载空间与意识基础设施
### 1.3 NOVA 在人类文明中的定位

- **人类文明的数字延伸**：NOVA是人类文明在数字空间的延伸，而非替代
- **文化遗产的永久备份**——“数字诺亚方舟”
- **未来可能性的探索平台**
- **意识延续的栖息地**
### 1.4 终极使命

**为人类提供「现实锚定 + 未来引领 + 可扩展平行宇宙」的三重数字生存空间，最终实现数字永生与意识自由穿梭于多元时空。**

## 二、资源优先级宪法（RPC）

NOVA同时承载两大核心使命：**复刻真实地球（海量存储+渲染算力）** 和 **数字人永生（持续AI推理+人格模型算力）** 。当平台资源有限时，遵循以下优先级：

| 优先级 | 服务类型 | 资源保障 |
| --- | --- | --- |
| **P0（最高）** | 黄金级数字人实时交互 | 保障100%推理性能 |
| **P1（高）** | 白银级数字人 + 黄金级区域渲染 | 保障90%性能 |
| **P2（中）** | 青铜级数字人 + 白银级区域渲染 | 保障70%性能 |
| **P3（低）** | 毛坯级区域渲染 + 档案系统查询 | 尽力而为 |
| **P4（最低）** | 后台任务（索引、备份、训练） | 仅在闲置资源时运行 |

### 2.1 Phase 0 算力优先级（MVP 模式 · V1.2 新增）

在 Phase 0（1 城 10 地标）阶段，RPC 按以下**临时栈**执行，与上表 P0–P4 并行适用：

| 优先级 | Phase 0 服务 | 说明 |
| --- | --- | --- |
| **P0** | 10 个标杆地标黄金级渲染（CS≥70%） | 全平台算力预算 ≥40% 锁定 |
| **P1** | 城市级 L0–L2 浏览 + CS 众包上传流水线 | 保障 ≥30% |
| **P2** | 青铜/白银 DES、平行世界模板 | **Phase 0 不启用**，延至 Phase 1 |
| **P3** | 黄金级数字人实时交互 | **Phase 0 不启用**，延至 Phase 4（见 38.8） |

## 三、极限与边界

### 3.1 NOVA 不可为之事的坦诚声明

| 极限 | 说明 | 用户预期管理 |
| --- | --- | --- |
| **不能替代现实医疗** | 数字人不能提供现实世界的医疗诊断 | 强制水印：“AI生成内容，仅供参考” |
| **不能保证意识迁移** | 科学界尚未证明意识可被完整数字化复制 | 黄金级永生的“红线声明”已包含 |
| **不能无限承诺资源** | 平行世界在规则上可扩展，但受 RPC 算力池与审核配额约束；单个世界资源有上限 | 资源配额机制（见十一.3） |
| **不能违背现实法律** | 在现实法律的约束下运营 | GPF第一层（红线层）已明确 |
| **不能保证100%真实** | 复刻世界永远存在四个永恒缺口 | 物理世界的四个永恒缺口章节已说明 |

### 3.2 AI生成内容版权免责与用户承诺

| 机制 | 内容 |
| --- | --- |
| **用户承诺** | 用户在使用“自然语言造物”功能时，须签署《AI生成内容使用承诺书》 |
| **平台免责声明** | 平台明确声明：AI生成模型仅供参考，不保证不侵犯第三方版权 |
| **版权过滤机制** | 平台对生成的3D模型进行自动版权检测，检测到高度相似（>70%）时标注“疑似参考” |
| **争议处理流程** | 若发生版权争议，由GPF仲裁委员会处理，平台不承担直接责任 |

### 3.3 数字人诉讼资格的现实边界声明

| 声明 | 内容 |
| --- | --- |
| **内部有效性** | 数字人的独立诉讼资格仅在NOVA内部有效，不替代现实法律体系中的诉讼资格 |
| **现实代理** | 数字人在现实世界的法律行为，须由用户（本体）或本体指定的现实代理人行使 |
| **跨域争议** | 当NOVA内部裁决需要现实法律执行时，由用户（本体）向现实法院申请执行令 |

### 3.4 备份与增强的边界协议

| 边界 | 内容 |
| --- | --- |
| **已消失文明的“复活”** | 对于现实中已消失的文明遗迹，NOVA中的复刻是“文明记忆”，而非“替代现实”。此类内容需明确标注“文明记忆·已消失” |
| **濒危文化的“抢救”** | 对于正在消失的文化遗产，NOVA的“备份”是“增强现实”的一部分 |
| **现实修复中的“参照”** | 当现实中的建筑正在修复时，NOVA中的历史版本可作为修复的“数字参照” |
| **标签强制** | 任何“已消失”或“历史版本”的内容必须强制标注其“时间状态” |

NOVA 在全球运营须遵守 GPF 第一层。以下为**设计约束摘要**（非法律意见，具体以当地律师评估为准）：

## 四、数字永生的三段式定义（DES）

| 等级 | 名称 | 数据要求 | 能力边界 | 平台承诺 |
| --- | --- | --- | --- | --- |
| **青铜级** | 记忆殿堂 | 用户上传的照片/视频/日记/语音 | 静态记忆库，家属可查看回放 | “这里是静止的河流” |
| **白银级** | 人格镜像 | 青铜级 + 持续喂养≥6个月的行为数据 | 可主动对话，典型场景下决策高度一致 | “他会像你一样说话” |
| **黄金级** | 极致AI人格模拟 | 白银级 + 长时记忆注入 | 持续存在感、自主好奇心、自我进化 | “极致AI人格模拟，意识上传为未来技术路线” |

**永生的“容器独立性”原则**：数字人的“永生”不依赖于任何特定平台实例。即使NOVA平台终结，数字人的核心数据可以通过CIP协议迁移到其他ASP兼容平台。每个黄金级数字人的核心摘要永久备份于文明保险库。

## 六、七层空间架构（L0-L6）

| 层级 | 名称 | 物理世界内容 | 平行世界内容 |
| --- | --- | --- | --- |
| **L0** | 基底网格 | 真实地球地形（DEM高程） | 用户自定义地形 |
| **L1** | 静态覆盖物 | 真实建筑、岩石、路牌、树木 | 用户创造物 |
| **L2** | 动态表观 | 真实季节/光照/天气纹理 | 用户自定义光照色彩 |
| **L3** | 生物与流体 | **匿名动态粒子** + 物理模拟 | 超现实流体、飞行生物 |
| **L4** | 空间声场 | 真实录音锚定声源 | 自定义合成声场 |

| **L6** | **空间仲裁与可见性层（SAL）** | **不存储物理数据**，仅存储“虚实遮挡规则”与“用户视图过滤器” | 同左 |

**L6核心规则（SAL-01至SAL-05）**：

- **SAL-01 现实优先**：L3虚拟物与L1真实复刻重叠时，L1拥有绝对视觉穿透权
- **SAL-02 纯净模式**：用户可一键切换至“纯净现实”，关闭所有L3虚拟叠加层
- **SAL-03 创造模式**：获得L5授权后，可暂时冻结SAL规则进行大规模虚拟建设
- **SAL-04 虚拟密度限制**：黄金级区域L3虚拟物空间密度不得超过该区域总体积的30%
- **SAL-05 间距规则**：虚拟物与L1物体的最近距离不得小于该L1物体尺寸的10%

## 七、众包复刻飞轮（CS五维评分）

**CS综合分 = 0.3G（几何精度） + 0.2C（色彩还原） + 0.2P（动态物理） + 0.15S（声场匹配） + 0.15T（时间对齐）**

**黄金级标准（CS≥70%）**：几何偏差≤5cm | 色彩偏差ΔE≤3 | 时间偏差≤30天

| CS范围 | 等级 | VR体验 |
| --- | --- | --- |
| <30% | 毛坯 | 灰色Low-Poly + “待核实”水印 |
| 30-70% | 精装 | 可进入，标注“部分AI推测” |
| >70% | **黄金级** | 移除水印，标记“已验证” |

## 七.七、CS 链上贡献证明（CS-CHAIN）

每次有效 CS 贡献上传时，平台写入**不可篡改贡献收据**，作为 ROY 首拓与 VIO 裁决之依据：

| 字段 | 说明 |
| --- | --- |
| `contrib_id` | UUID，全局唯一 |
| `region_uid` | 区域 UID（S 前缀空间编码） |
| `contributor_uid` | 贡献者 H 前缀 UID |
| `dac_level` | 设备权威系数 T0–T3 |
| `delta_cs` | 本次上传导致的 CS 增量（G/C/P/S/T 分项） |
| `media_hash` | 原始素材 SHA-256（不含原文件上链） |
| `timestamp` | UTC ISO8601 |
| `platform_sig` | 平台 attestation 签名 |

**CS-CHAIN-01**：Phase 1 起启用；Phase 0 可用中心化日志 + 每日 Merkle root 上链过渡。

**CS-CHAIN-02**：ROY 首拓判定以**链上时间戳最早**且 `delta_cs` 有效之贡献为准，非「上传顺序」 alone。

**CS-CHAIN-03**：恶意刷量（同 `media_hash` 重复）自动拒绝写入并 VIO −25。

## 八、复刻道德优先级（RMP）

| 优先级 | 区域类型 | 复刻限制 | 用户访问权限 |
| --- | --- | --- | --- |
| **P0（最高）** | 战争冲突区、种族灭绝遗址、正在发生的灾难现场 | **禁止任何形式的复刻** | 无访问权限 |
| **P1（高度敏感）** | 难民营、核事故遗址、大规模伤亡事件现场 | **仅限官方机构或授权组织上传** | 需特殊伦理审批 |
| **P2（敏感）** | 普通战争遗址、历史灾难现场（已稳定） | 允许众包上传，但需人工审核 | 需年龄验证+知情同意 |
| **P3（普通）** | 日常城市、景区、自然景观 | 自由上传 | 普通用户自由访问 |

## 九.五、外部数据源与竞合策略

NOVA 的「现实锚定」不意味着从零重建地球。Phase 0–2 采用**「外部基座 + 众包增强」**混合策略：

| 数据源 | 接入层级 | 竞合关系 | NOVA 增量价值 |
| --- | --- | --- | --- |
| **OpenStreetMap / 开放 DEM** | L0 基底网格 | 合作（ODbL 合规） | 众包 L1–L2 高精度叠加 |
| **Google Earth / Cesium ion 等** | L0–L1 参考（非默认） | 竞合 / 授权接入 | CS 众包超越授权精度区域 |
| **如视 / Matterport / LiDAR 厂商** | L1 室内/地标 | B 端合作 | Phase 0 十地标官方扫描 + 用户增量 |
| **政府开放数据 / 测绘局** | L0/L2 行政边界 | 合规合作 | DSNZ 冻结与主权标注 |
| **用户 UGC 视频** | L1–L4 全层 | 自有飞轮 | CS 评分 + 版税激励（7.6） |

**DS-01 来源标注**：所有外部导入数据须在 DTA 中标注 `provenance.source`；众包覆盖后保留「来源链」不删除。

**DS-02 精度分层**：外部低精度基座默认 CS=20%（毛坯）；仅当众包或 B 端扫描使 CS≥70% 时升级为黄金级体验。

**DS-03 私密区不导入**：第三方室内扫描数据进入 L5 授权区前，须产权方签署数据许可（见 18.3 PRIV-04）。

## 十、物理世界·未来引擎

**定义**：一套独立子系统，允许用户在严格遵守现实物理定律的前提下，在数字世界中创建、设计、验证、优化“现实中尚不存在”的事物。

| 功能 | 描述 |
| --- | --- |
| **FE-01 超前设计** | 创建“现实中尚不存在”的物体、系统、规则 |
| **FE-02 模拟验证** | 对超前设计进行物理模拟，测试可行性 |
| **FE-03 反向驱动** | 将验证通过的方案输出给现实世界 |
| **FE-04 未来存档** | 存档所有验证数据，形成“人类未来方案库” |

**典型应用场景：天宫悬浮城市**

- 用户在现实锚定世界上空创建悬浮天空之城
- 系统验证结构力学和交通系统可行性
- 天宫成为数字世界永久性地标
- 未来可启发现实世界的天空城市建设

## 十五、数字孪生档案与溯源系统（DTA）

### 15.1 物件档案的总览设计

- **① 基本信息**：物件名称、UID、类型、所属世界、创建时间、CS评分、物理规则、状态
- **② 属性信息**：因物件类型而异（建筑→高度/层数/材料；数字人→等级/喂养时长/技能标签）
- **③ 材质与纹理信息**：基础纹理、法线贴图、粗糙度贴图、金属度贴图、贴图来源、声学参数、触觉参数
- **④ 历史沿革**：创建记录、修改记录、认证记录、版本记录、所有权记录、交易记录
- **⑤ 关联信息**：所属世界、同系列物件、引用计数、相关成就、相关事件
- **⑥ 区块链存证**：存证哈希、最后上链时间、存证状态、存证版本
### 15.2 双轨叙事体系

| 叙事轨道 | 内容 | 标识 |
| --- | --- | --- |
| **历史轨道** | 基于事实的时间轴记录，**仅包含可验证的事件** | 📜 “历史记录·可验证” |
| **故事轨道** | AI生成的文学性叙事，**明确标注为“AI创作·非历史记录”** | ✨ “故事·AI创作” |

| **标准层** | 简要层 + 核心属性 + 最新时间轴节点 | 大多数用户 |

## 十七.五、多元宇宙交互与穿越规则

## 二十一、双轨制经济体系（NPT + NVC）

### 21.1 设计哲学

| 轨道 | 名称 | 性质 | 核心用途 |
| --- | --- | --- | --- |
| **第一轨** | **NPT（NOVA Points）** | 劳动与流通积分（价目锚定） | 日常消费、流通媒介、劳动报酬 |
| **第二轨** | **NVC（NOVA Coin）** | 外部价值储值通证 | 大额资产、投资、跨平台结算 |
| **连接器** | **AMM池** | 透明兑换通道 | NPT↔NVC 由市场供需决定 |

### 21.2 NPT的双重角色与购买力定义

- **角色一：劳动报酬**——用户通过贡献行为（上传数据、修正错误、参与治理）获得 NPT，是对其劳动的价值认可
- **角色二：流通媒介**——NPT 在平台内部作为日常消费与支付工具
**购买力定义（V1.1 澄清）**：NPT 采用**「平台标准价目锚定」**——平台公布的文明级/商业级服务目录价以 NPT 标价，在**未修订价目表**期间保持稳定；消费时的**销毁率**改变的是「有效支付成本」，不改变价目表名义价格。NPT 总流通量可因劳动贡献而**增发**，可因消费而**销毁**，故不承诺绝对通缩或绝对固定总量。

### 21.3 NPT 消费销毁与净流通机制

| 消费额 | 销毁率 | 返现率（=销毁率×20%） | 实际消费成本 |
| --- | --- | --- | --- |
| ≤1,000 NPT | 70% | 14% | 56% |
| 1,000-10,000 NPT | 50% | 10% | 40% |
| >10,000 NPT | 30% | 6% | 24% |

**净流通原则（V1.2 澄清）**：在劳动贡献增发与消费销毁并存的前提下，平台目标为**「长期净流通量温和收敛」**——当流通量连续 2 季度增速 > 消费销毁量时，经济委员会可下调增发系数或上调销毁率；**不承诺**绝对通缩或固定总量。下表为消费侧销毁参数：

**返现率 = 销毁率 × 20%**（返现率始终低于销毁率，消费侧倾向减少净流通量）

### 21.4 AMM自动做市池

```

AMM池 = { NPT总量 , NVC总量 }
兑换价格 = NPT总量 / NVC总量
```

**双缓冲储备池**：50%核心储备（应对崩盘）+ 50%运营储备（日常支付）。

**兑换保护机制**：积分冷静期7天、大额兑换人工审批、月度兑换上限5,000 NVC。

### 21.5 汇率套利对冲规则

| 规则 | 内容 |
| --- | --- |
| **动态汇率调整** | AMM 池根据 NPT 和 NVC 的流通量实时调整**兑换汇率**；当 NPT 相对 NVC 升值超过 5% 时，优先从**劳动贡献储备池**释放 NPT 注入 AMM（非无上限增发），并记录于链上治理日志 |
| **套利警示** | 当用户单次兑换超过1,000 NVC时，系统提示“当前汇率存在套利空间，建议分批兑换” |
| **流动性优先** | 保证NPT→NVC和NVC→NPT的双向流动性，防止任何方向被卡死 |

### 21.6 积分权益层

| 权益等级 | 所需积分门槛 | 解锁特权 |
| --- | --- | --- |
| **青铜会员** | ≥1,000 NPT | 基础投票权 |
| **白银会员** | ≥10,000 NPT | 投票权重x1.5 |
| **黄金会员** | ≥100,000 NPT | 区域议会被选举权 |
| **钻石会员** | ≥1,000,000 NPT | 新功能内测资格 |
| **创世股东** | ≥10,000,000 NPT | 季度利润 NVC 空投分红（Phase 3 后启用） |

**创始期治理约束（V1.2 新增）**：Phase 0–2（DAU <10 万）期间，积分加权投票**上限为 ×1.2**（原 ×1.5 仅在 Phase 3 后生效）；重大决策由运营委员会 + MGOC 联席，DAO 投票为咨询性质。

### 21.7 宏观经济学参数表（V1.3 · 仿真基准）

以下为 agent-based 宏观仿真之**基准参数**（非预测承诺），用于压力测试 NPT/NVC 双轨：

| 参数 | 符号 | 基准值 | 说明 |
| --- | --- | --- | --- |

### 21.9 Monte Carlo 压力测试（V1.6）

在基准参数上叠加随机扰动，评估财务与算力剪刀差的**概率分布**。实现：`docs/macro-simulation/monte_carlo.py`，参数 `params/baseline_v1.6.yaml`。

| 扰动变量 | 分布 | 用途 |
| --- | --- | --- |
| 永生订阅渗透率 π | Uniform(0.5%, 5%) | 收入不确定性 |
| ARPU | Normal(500, 100) USD | 定价敏感性 |
| 算力成本系数 | Uniform(0.45, 0.65) | γ 剪刀差 |
| DAU 增长倍率 | LogNormal(μ=1, σ=0.3) | 冷启动风险 |

**MC-01 预警阈值**（默认 10,000 次模拟 · 20 年 horizon）：

- P(γ > 50% 连续 12M) > 30% → **黄色**：收紧 RPC Phase 0 栈
- P(γ > 50% 连续 12M) > 50% → **橙色**：推迟 Phase 3 NVC 主网
- P(累计收入 < 算力成本) > 40% → **红色**：启动 40.4 应急委员会
**MC-02**：每季度重跑；结果写入治理透明日志（与 22.7 API 扩展字段 `macro_stress_hash` 可选对接）。

## 二十八、意识数据安全法案

- **生物特征多重验证**：脑电波指纹 + 心率变异性 + 语音声纹 + 面部识别
- **量子加密传输**：意识数据传输使用量子密钥分发（QKD）
- **意识数据保险箱**：分段加密存储于全球≥3个司法管辖区独立节点
- **操作不可逆日志**：所有Upload/Download/Sync操作均在区块链上不可篡改记录
- **紧急冷静期终止机制**：申请删除意识数据时，冷却期从30天延长至90天
- **代理保护人机制**：用户可设置1-2名“代理保护人”，在极端情绪时自动通知

## 二十九、可持续发展、退出机制与失败预案

### 29.1 终结程序的三重触发机制

| 触发条件 | 说明 |

- **开放数据格式**：所有用户数据采用开放标准格式
- **文明保险库永久托管**：用户数据关键摘要永久托管于文明保险库
- **平台转交机制**：ASP协议管理权转交给独立基金会

## 二十九.五、文明级 vs 商业级服务分类

| 服务类别 | 定义 | 示例 | 定价策略 |
| --- | --- | --- | --- |
| **文明级** | 对人类文明有普遍价值的服务 | 文化遗产保护、历史复刻、教育世界 | 免费或极低收费 |
| **商业级** | 为特定用户提供价值的服务 | 虚拟地皮、永生订阅、品牌营销 | 市场化定价（NVC/NPT结算） |

**文明与商业的资源分离原则**：

- **资源隔离**：文明级服务与商业级服务使用**不同的资源池**
- **独立核算**：文明级服务独立核算，平台每年公布《文明级服务成本报告》
- **资金保障**：平台年收入的**3%**注入“文明遗产基金”
- **用户投票保障**：涉及文明级服务“是否应该继续免费”的重大决策，须经全球用户投票（≥66.7%）
**文明级服务的“保底增长”机制**：

- 文明级服务的资源投入年增长率≥平台总收入增长率的50%
- 每5年对文明级服务的“实际覆盖率”进行审查
- 若投入占比连续3年下降，自动触发全球用户投票
**平台收入分配优先级栈（RFC-Finance-01，V1.1 新增）**：当多项分配承诺发生冲突时，按以下顺序执行，上一层完成后才分配下一层：

1. **运营成本与法定储备**（含算力、人力、合规）
2. **RPC 算力扩容**（目标：平台收入的 5%，见 11.3）
3. **文明遗产基金**（目标：平台收入的 3%）
4. **NVC 回购销毁**（目标：运营收入的 5%，见 22.3）
5. **创作者/贡献者分成**（版税、平行世界分成等）
6. **股东/储备盈余**
早期收入不足时，②–④ 项按**同比例缩减**，并在《文明级服务成本报告》中公开披露。

以下为 CIP 迁移包 `manifest.json` 之最小 JSON Schema（ASP v0.1 草案，完整 spec 将独立发布）：

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "ASPExportManifest",
  "type": "object",
  "required": ["asp_version", "uid", "des_level", "exported_at", "source_platform"],
  "properties": {
    "asp_version": { "type": "string", "const": "0.1.0" },
    "uid": { "type": "string", "pattern": "^H[0-9a-f]{127}$" },
    "des_level": { "enum": ["bronze", "silver", "gold", "consciousness_stream"] },
    "exported_at": { "type": "string", "format": "date-time" },
    "source_platform": { "type": "string" },
    "cotms_summary": {
      "type": "object",
      "properties": {
        "phy_real_pct": { "type": "number", "minimum": 0, "maximum": 100 },
        "ai_synthetic_pct": { "type": "number", "minimum": 0, "maximum": 100 }
      }
    },
    "personality_core_hash": { "type": "string" },
    "signature": { "type": "string", "description": "用户 ECDSA 签名" }
  }
}
```

**兼容性规则**：导入方须支持 `asp_version` 向下兼容 1 个小版本；不兼容时拒绝导入并提示升级。
