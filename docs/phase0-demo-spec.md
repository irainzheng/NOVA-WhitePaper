# Phase 0 标杆城 Demo 环境规范

> 白皮书 V1.5.0 · 40.7  
> 对外演示、投资人 walkthrough、媒体预览专用，**与生产环境隔离**。

---

## 1. 目标

- 在 **不污染生产 CS-CHAIN / NPT 账本** 的前提下，展示 Phase 0 核心体验  
- 满足 P0-02（10 地标 CS≥70% VR 可进）的可视化证明  
- 显式合规标注，避免 Demo 被误认为已上线 NVC/Zone C  

## 2. 架构

```
┌─────────────────┐     ┌──────────────────┐
│  demo.nova.*    │────►│ Demo API Gateway │
│  (CDN + WebGL)  │     │  read-only roam  │
└─────────────────┘     └────────┬─────────┘
                                 │
                    ┌────────────┴────────────┐
                    ▼                         ▼
            ┌───────────────┐         ┌───────────────┐
            │ Demo CS Pipe  │         │ Sandbox NPT   │
            │ (no mainnet)  │         │ 10k credits   │
            └───────────────┘         └───────────────┘
```

| 组件 | 生产 | Demo |
|------|------|------|
| CS-CHAIN | 主网 Merkle | 沙箱链 / 日清空 |
| NPT | 真实增发销毁 | 预置额度，无提现 |
| NVC / AMM | 不可见（Zone B） | **禁止出现任何入口** |
| 用户数据 | 持久 | 7 天 TTL 或演示结束清除 |

## 3. 功能范围

### 3.1 必开（P0 Demo）

- [ ] 选定 1 城 L0 漫游（与 P0-01 一致）  
- [ ] 10 地标 VR 进入，CS≥70% 徽章可见  
- [ ] 3 条预置导览路线（官方语音/字幕）  
- [ ] 众包上传 → 沙箱 CS 评分（≤5 分钟流水线）  
- [ ] DTA 简要层查询（UID 搜索）  
- [ ] 页脚：**「Demo · Zone B 模拟 · 非最终产品」**  

### 3.2 可选（P1 Demo）

- [ ] ASP export 生成 sample manifest（不导出真实用户）  
- [ ] NPT 贡献模拟（+50 日上限演示）  
- [ ] 文明宪章注册流程预览  

### 3.3 禁止

- 真实法币支付、KYC、NVC 钱包  
- 生产用户账号直通  
- 黄金 DES / 意识流演示（预期管理，见 Review Memo）

- 无 PII 收集；分析仅聚合指标
