## Scope of Work

### Deliverable A — 10 Landmarks (required)

| # | Requirement |
|---|-------------|
| A1 | LiDAR and/or high-resolution panoramic capture per landmark |
| A2 | Processed assets: glTF 2.0 and/or 3D Tiles 1.1 |
| A3 | **CS ≥ 70%** per NOVA 5D scoring (vendor pre-estimate + 48h pilot) |
| A4 | DTA-ready metadata: coords, capture date, device, operator |
| A5 | `provenance.source` = vendor ID (RFP-02) |

### Deliverable B — L0 Base QA (required)

- Validate OSM + DEM inside city bbox  
- Gap rate ≤ **0.1%** (P0-03)  
- Report with screenshots + automated test output  

### Deliverable C — SLA (required)

- Sign [data-source SLA](../data-source-sla-template.md) (九.六)  
- Quarterly incremental update clause for Phase 0 duration  

---

## Pilot Requirement (RFP-01)

Bidders must complete **one pilot landmark within 48 hours** of shortlist notification.

- Blind CS estimate by NOVA Technical Committee  
- Minimum pilot score: **CS ≥ 60%** to remain on shortlist
