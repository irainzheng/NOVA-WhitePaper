## 📖 简介

NOVA 白皮书是一份 **数字文明的宪法级文档**。它是一份关于“人类如何将文明延续到数字世界”的系统性构想。

### 核心定位
> 这不是一个平台的白皮书，这是一份数字文明的宪法。

### 文明价值主张
> **NOVA是一个“现实锚定的、可永续进化的、值得居住的数字文明。”**
